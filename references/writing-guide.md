# Tailoring guide (G1-G8)

Use these when rewriting bullets for a specific job. Cite the rule ID next to every proposed change.
The bullet checklist R1-R10 in role-playbooks.md covers basic quality; G1-G8 cover tailoring.

| ID | Name | Rule |
|---|---|---|
| G1 | Action + how + result | Start with a precise action verb, then what you did, how (tools, methods), and the result. Result-first is fine when the result is the strongest part. |
| G2 | Specific over impressive | A concrete detail (scale, tool, scope, outcome) beats vague or inflated wording. Not every bullet needs a dramatic result. |
| G3 | Mirror the employer's words | Use the posting's terms only when they truthfully describe the work. Work them into evidence; never keyword-stuff. |
| G4 | Quantify what's real | Show scale, speed, accuracy, growth or volume with numbers the user gave. Never invent or round up a number. |
| G5 | Reposition, don't rewrite history | Tailoring means emphasizing, reordering and rephrasing. Strong evidence: make it visible. Moderate: strengthen it. Gap: leave it out. |
| G6 | Prove the skill, don't list it | Show where and how a skill was used instead of naming it alone. |
| G7 | Answer the bigger need | Ask what problem the employer is hiring for, and point the line at that need and at themes the posting repeats. |
| G8 | Easy to scan | Keep lines concise, consistent in tense and style, and readable in a 6-10 second scan. |

## Examples (fictional, for style only)

- Weak: "Responsible for the onboarding flow."
- Stronger (G1, G2): "Redesigned the 4-step onboarding flow with design and engineering, cutting drop-off from 38% to 24%"
- Targeted for a growth PM role (G3, G7): "Led an onboarding redesign to improve new-user activation, cutting step drop-off from 38% to 24% through A/B tests"

- Weak: "Did user research."
- Stronger (G1, G6): "Ran 12 user interviews and a 300-person survey to find why trial users churned, and turned the findings into 3 roadmap items"

## Evidence map (G5)

| Evidence for a job requirement | What to do |
|---|---|
| Strong | Make it visible: move it up, lead the bullet with it |
| Partial | Strengthen the bullet with true detail; ask the user for missing facts |
| None | Leave it out. Tell the user it's a gap and suggest how to close it (project, course, cover letter) |
